# 出题与预测质量

## 蓝图与证据

先记录材料的年份、岗位、题型、原编号和可读程度。多份材料区分独立年份与同题转载，不能把转载次数算作考频。整理 `模块 → 原题证据 → 所测能力 → 本卷题数 → 难度`；题量应服从用户要求，不把一个词面变化重复几十次凑数。

根据材料证据区分：明确反复出现、单份材料出现、相关能力扩展。用这些标签解释训练优先级；资料稀少时承认覆盖有限。不要将主观推测写成统计命中率，不宣传官方押题或真实题库。

用户只给知识点时，围绕定义、适用条件、计算、场景判断和常见错误变化题型；参考往年题时保留大致阅读量、计算量和推理深度。拿到新截图后，先核对是否属于已有卷，不强制一张图一套新卷。

## 选择题

- 单选只允许一个正确选项；多选声明全对得分或用户指定规则。附解释，说明成立条件及主要干扰点。
- 干扰项来自真实误区，例如忘乘内层导数、把 Recall 和 Precision 混淆、把 token 位置维与特征维混淆、把窗口半径当长度、矩阵转置/输入方向错误。
- 避免多个数学上等价的选项；若理论结论需要独立性、紧致集、适当激活、无裁剪等条件，放进题干。
- 随机化选项后同步答案，用文本或内部稳定键定位正确项，不在打乱后沿用旧字母。解析尽量引用选项内容，不依赖会变化的字母。
- 正确项在长短和措辞上不应始终突出；避免全部为“以上都对”和无意义荒诞干扰项。
- 不能确定的原题答案要复核，必要时保留在待核对清单，不计入正式试卷；不要用猜测当判分标准。

## ACM 编程题

明确输入按行还是可任意空白、测试组数、数据规模、矩阵形状、索引起点、边界窗口、相同最优解的取舍、舍入/误差容限和非法输入行为。截图没有规定的条件应写成“模拟补充约定”。

准备独立参考实现；公共样例置于 tests[0]，其余为隐藏测试。隐藏测试至少覆盖一般情况、最小规模、边界、数值/溢出风险和一种常见错误。浮点判题使用有限值及明确容差，不接受 NaN/Infinity。穷举小数据与优化算法对拍，或手算样例后再扩展随机测试。

计分按已声明的规则；模板以通过测试数量的比例计分。缺少可靠参考和测试时，不宣称已经可自动判题。

## 讲解模式

如果用户在考试后问代码含义，直接围绕其样例解释，暂时不扩题。以滑动窗口注意力为例：一个 token 对应 Q/K/V 的一行，seq_len 管位置范围，d_k 管点积列循环；“左右”描述序列前后，矩阵按行排时视觉上为上下。选择非方阵小例子避免两个维度相等造成误解。
